# Green Life

植物と人との関係をデザインする、架空の会社「Green Life株式会社」のWebサイトです。

## サイト概要

植物の販売・レンタル・空間デザインを通して、植物のある暮らしを提案するコーポレートサイトとして制作しました。

## 公開サイト

https://sabakan-miso.github.io/GreenLife/

## 使用技術

- HTML
- CSS
- JavaScript
- Vite
- ScrollReveal
- Splide

## 制作目的

Webデザインおよびフロントエンドの学習を目的として制作した架空のWebサイトです。
